# Data Science Full-Stack Portfolio

A collection of independently implemented data science and full-stack applications spanning machine learning, forecasting, analytics, workflow orchestration, and interactive product development. Each project includes reproducible setup instructions, working functionality, validation evidence, and clear documentation.
