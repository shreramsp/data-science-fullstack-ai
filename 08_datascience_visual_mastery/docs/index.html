1. Naive Bayes

Bayes' theorem turns a likelihood into a posterior belief:

P(class | x) = P(x | class) · P(class) / P(x)

The "naive" assumption: features are conditionally independent given the class, so a multi-feature likelihood is just a product of simple per-feature likelihoods. Worked example: a spam filter sees the word "free". Suppose P(free | spam) = 0.4, P(free | ham) = 0.05, and the prior P(spam) = 0.3. Then:

P(spam | "free") = (0.4 × 0.3) / (0.4 × 0.3 + 0.05 × 0.7) = 0.12 / 0.155 ≈ 0.77

Even though "free" alone isn't proof of spam, it shifts the posterior from a 30% prior up to about 77%. The live 2-D contour simulation for this concept is in the Streamlit app (streamlit run app.py).

2. Model Evaluation

Type I error (false positive): predicted positive, actually negative. Type II error (false negative): predicted negative, actually positive. Moving the decision threshold trades one off against the other.

4. Chain Rule & Backprop

d/dx f(g(x)) = f'(g(x)) · g'(x)

A tiny network: z1 = w1·x + b1, a1 = tanh(z1), ý = w2·a1 + b2, L = ½(ý - y)². Backprop multiplies local derivatives layer by layer, back to front. Worked example with x=1, y=0.5, w1=0.8, b1=0, w2=-0.6, b2=0:

z1 = 0.8 → a1 = tanh(0.8) ≈ 0.664 → ý = -0.398
dL/dý = ý - y = -0.898
dL/da1 = dL/dý · w2 = 0.539
da1/dz1 = 1 - tanh(z1)² ≈ 0.559
dL/dz1 = 0.539 × 0.559 ≈ 0.301
dL/dw1 = dL/dz1 · x ≈ 0.301

The full training simulation (loss curve + learned fit to sin(x)) is in the Streamlit app.
